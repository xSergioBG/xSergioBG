# Hola, soy Sergio

Desarrollo proyectos web, aplicaciones móviles y herramientas de línea de comandos. Este perfil reúne ejemplos de código, plantillas reutilizables y material de aprendizaje.

Trabajo con **JavaScript, TypeScript, Python y C#**, y con **React, React Native, Node.js y .NET**.

## Cómo está organizada mi colección

- **Herramientas y ejemplos:** CLIs, caché y comunicación con RabbitMQ.
- **Web y móvil:** proyectos con React, Astro, ASP.NET Core y React Native.
- **Plantillas:** puntos de partida para aplicaciones y documentación.
- **Aprendizaje:** guías y ejercicios de Python y Java.

Los proyectos tienen alcances distintos. Cada README explica la instalación, el estado y los límites del repositorio. Los ejercicios y prototipos forman parte del recorrido de aprendizaje.

Consulta el [catálogo de repositorios públicos](REPOSITORIES.md) para navegar por temas.
